# Minimal Dash (لوحة تحكم مصغرة)

[English](#english) | [العربية](#العربية)

---

## English

A minimal command-line dashboard built with Python that displays the current weather, currency rates, and a daily motivational quote.

### Features
* **Weather Updates:** Displays current temperature and wind speed for Safita.
* **Currency Rates:** Tracks live exchange rates for USD to EUR and GBP.
* **Daily Quote:** Displays an inspirational quote to boost your productivity.

### Requirements
This project requires Python 3 and the `requests` library.
To install the dependencies, run:
```bash
pip install requests
```

### How to Run
1. Clone the repository or download the `main.py` file.
2. Open your terminal or command prompt in the project directory.
3. Execute the script using:
```bash
python main.py
```

## العربية

لوحة تحكم مصغرة تعمل عبر سطر الأوامر (Terminal) مبنية باستخدام لغة بايثون، تعرض حالة الطقس الحالية، أسعار العملات، واقتباساً تحفيزياً يومياً.

### المميزات
* **تحديثات الطقس:** عرض درجة الحرارة وسرعة الرياح الحالية لمدينة صافيتا.
* **أسعار العملات:** متابعة حية لأسعار صرف اليورو والجنيه الإسترليني مقابل الدولار الأمريكي.
* **اقتباس يومي:** عرض اقتباس ملهم لزيادة إنتاجيتك وبدء يومك بنشاط.

### المتطلبات
يتطلب هذا المشروع وجود بايثون 3 وتثبيت مكتبة `requests`.
لتثبيت المكتبات المطلوبة، نفّذ الأمر التالي:
```bash
pip install requests
```

### كيفية التشغيل
1. قم بتحميل ملف `main.py` أو نسخ المستودع إلى جهازك.
2. افتح نافذة الأوامر (Terminal) في مجلد المشروع.
3. قم بتشغيل السكربت باستخدام الأمر التالي:
```bash
python main.py
```
